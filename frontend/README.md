# Frontend — Fashion Sales Chatbot

Vite + React + TypeScript + Tailwind + shadcn/ui.

## Cài

```bash
npm install
```

## Dev

```bash
npm run dev
```

Mở http://localhost:5173 (chat) hoặc /admin (quản trị).

Vite proxy `/api/*` → `http://localhost:8000` (đảm bảo backend đang chạy).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 18, TypeScript 5
- Vite 5
- Tailwind CSS 3
- shadcn/ui components (Button, Input, Textarea, Card, Label, Badge)
- react-router-dom 6
- lucide-react (icons — đã cài, sẵn sàng dùng)
